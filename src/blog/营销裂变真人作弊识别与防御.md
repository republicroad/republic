
识别真人作弊团伙是拉新裂变风控中最具挑战性的问题之一。与机器脚本不同，真人作弊团伙拥有真实设备、真实手机号、甚至真实身份，但通过组织化、规模化的方式骗取奖励。他们的核心特征是：看似每个账号都是“正常用户”，但群体行为存在异常关联。

# 攻击模式

营销场景一般有如下风险模式。和客户的沟通中，我们了解到客户已经有了非常完善的防御体系。

|**特征维度**|**具体表现**|**备注**|
|---|---|---|
|邀请关系|<br>星型结构（一个上级大量下级）<br>~~形成闭环（A→B→C→A） ~~<br>|通过数盟能力\+自研风控规则，将账号、设备、手机号、提现账户、支付账户、收货地址等多维度信息交叉关联，并对设备与账号做严格的一对一绑定，以确保参与活动的身份唯一|
|时间模式|邀请集中在特定时段（如夜间）<br>间隔高度均匀或高度聚集|可以使用 Dynamic Time Warping，动态时间规整来挖掘时间序列异常|

# 防御策略

针对客户已经梳理的黑产手法:


在裂变活动中，作弊者和真实用户的行为模式在时间轴上往往有明显区别。由于作弊者的操作节奏往往呈“爆发式”或“机械均匀”，而真实用户是随机稀疏的，通过动态时间规整计算行为轨迹的相似度，可以有效聚类异常账户，发现行为高度一致的作弊群体: 
- 使用 DTW 进行行为序列建模，计算邀请者多次邀请的时序相似度
- 使用图关系网络算法发现老带新之间的关联关系
- JS 散度

## JS散度

> 适合识别“步调高度一致”的团伙欺诈
> 寻找相对于整体基线具有高 JSD，但自身内部具有低 JSD的用户集群

### 定义

JS散度全称是詹森\-香农散度（Jensen\-Shannon Divergence），基于KL散度构建的对称且平滑的分布距离度量。

计算公式：
设 $M=\frac{1}{2}(P+Q)$（即两个分布的平均值），则：
$D_{KL}(P∥Q)= \sum_{i=1}^{n}P(i)⋅log\frac{P(i)}{Q(i)}$                                                KL 散度
$JSD(P∥Q)=\frac{1}{2}D_{KL}(P∥M)+\frac{1}{2}D_{KL}(Q∥M)$                     JS 散度


两大核心优势（对比KL）：
- 对称性：JSD\(P,Q\) = JSD\(Q,P\)。这意味着计算A团伙与B团伙的相似度，不会因为方向不同而得出不同结论，非常适合做两两聚类。
- 有界性：如果使用以2为底的对数，JS散度的值永远在 \[0, 1\] 之间。0代表两个分布完全一致，1代表完全相反。这个“百分比式”的数值非常直观，便于风控运营设定统一阈值。

### 团伙检测的具体步骤

团伙检测的核心要点是根据**群体内同质性**和**群体间异质性**来识别异常聚集用户。
离线数据挖掘步骤：
1. 选定一批高质量的客户，计算客户相关维度的JSD分布。
2. 将所有用户与“正常基线”进行比较。如果一个群体的JSD和正常基线相比差异大。则取出这些"离群差异"用户。
3. 计算这些差异用户间的JSD差异，如果这部分异常群体样本内的JSD差异比较小，是紧密聚集的异常值，那么此群体极有可能这是一个异常团伙。

### 代码示例

Jsd sql 计算示例:

```SQL
*-- 我们假设有两个分布，它们描述了在三个类别（A、B、C）上的概率：*
***-- 分布 P****：A: 0.4, B: 0.4, C: 0.2*
***-- 分布 Q****：A: 0.5, B: 0.3, C: 0.2*
*-- 在 DuckDB 中，我们分别用两张表来表示它们：*
*-- 创建并填充分布 P 的表*
CREATE OR REPLACE TABLE dist_p AS
    SELECT 'A' AS category, 0.4 AS prob
    UNION ALL SELECT 'B', 0.4
    UNION ALL SELECT 'C', 0.2;
*-- 创建并填充分布 Q 的表*
CREATE OR REPLACE TABLE dist_q AS
    SELECT 'A' AS category, 0.5 AS prob
    UNION ALL SELECT 'B', 0.3
    UNION ALL SELECT 'C', 0.2;
*--下面的 SQL 语句将基于这两个表计算 JS 散度。JS散度的数学定义为 JSD(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)，其中 M = 0.5 * (P + Q)，KL 代表 KL散度。*
WITH
  combined AS (
    *-- 步骤 1：将两个分布按类别合并，并计算平均分布 M*
    SELECT
      COALESCE(p.category, q.category) AS category,
      p.prob AS p_prob,
      q.prob AS q_prob,
      (COALESCE(p.prob, 0) + COALESCE(q.prob, 0)) / 2.0 AS m_prob
    FROM
      dist_p p
      FULL OUTER JOIN dist_q q ON p.category = q.category
  ),
  kl_terms AS (
    *-- 步骤 2：计算用于 KL 散度的各个项 p * log(p/m) 和 q * log(q/m)*
    SELECT
      *-- 注意：当概率为 0 时，对数无定义，因此用 CASE 语句处理*
      CASE
        WHEN p_prob > 0 THEN p_prob * LOG(p_prob / m_prob)
        ELSE 0
      END AS kl_p_term,
      CASE
        WHEN q_prob > 0 THEN q_prob * LOG(q_prob / m_prob)
        ELSE 0
      END AS kl_q_term
    FROM
      combined
  )
  *-- 步骤 3：汇总计算最终的 JS 散度*
SELECT
  0.5 * SUM(kl_p_term) + 0.5 * SUM(kl_q_term) AS js_divergence
FROM
  kl_terms;
```

## 行为序列挖掘（DTW）

DTW（Dynamic Time Warping，动态时间规整） 是一种用于衡量两个时间序列之间相似度的算法。它的最大特点是可以对齐不同步、不同长度的序列，从而比传统的欧氏距离更灵活、更准确。DTW 能够“扭曲”时间轴，让两个形状相似但在时间上不对齐的序列能匹配上。

这是一种让两个“节奏不一样”的时间序列能够“对上拍”的相似度算法，在裂变风控中常用于聚类识别脚本化的均匀邀请行为，是检测批量机器人邀请的有效手段之一。

### 脚本化邀请场景识别

真实用户的邀请行为：

- 随机时间间隔（几分钟、几小时、甚至几天）
- 邀请人数较少（通常 1–5 人）
- 邀请时间分布不规则

作弊用户的邀请行为：

- 时间间隔高度均匀（如每 30 秒邀请一次）
- 短时间内爆发式邀请（如 1 分钟内 20 次）
- 行为模式极其相似（脚本自动执行）

### DTW 使用方法

1. 提取用户邀请序列
对每个用户，记录其邀请行为的时间点，转化为时间间隔序列或累积邀请数序列。
2. 计算用户间 DTW 距离
如果一个用户的序列，与已知的“脚本模板序列”的 DTW 距离很小，或者一群用户互相之间 DTW 距离都很小（形成聚类），则这些用户很可能是作弊脚本控制的。
3. 聚类检测
对大量用户的邀请时间间隔序列，用 DTW 作为相似度度量，结合聚类算法（如 K\-medoids），找出密集的异常簇。

### 示例

真实用户 A 的邀请间隔（分钟）：`[2, 15, 143, 6, 58]`
作弊用户 B 的邀请间隔：`[1, 2, 4, 5, 3]`
脚本模板 C：`[1, 1, 1, 1, 1]`（每秒 1 次）

用 DTW 计算， DTW\(A, C\)  距离大，DTW\(B, C\)距离小，可以得到B的行为模式和已知的脚本C的行为模式更加接近。判定为疑似脚本请求。

```Python

from dtaidistance import dtw
import numpy as np
c = [1, 1, 1, 1, 1]
a = [2, 15, 143, 6, 58]
b = [1, 2, 4, 5, 3]

dtw.distance_fast(np.array(c,dtype=np.double), np.array(a,dtype=np.double))
# 153.73678805022564

dtw.distance_fast(np.array(c,dtype=np.double), np.array(b,dtype=np.double))
# 5.477225575051661
```



## 关系网络挖掘（图算法）

关系网络挖掘的目标是发现真人作弊团伙。使用图算法对于师傅邀请徒弟这种老带新的关系进行图建模。对于这种场景，建议使用同构图建模，也就是以用户作为图的节点，边可以考虑业务中存在的聚集关联字段：

### 构建图

- 节点：用户ID
- 边类型：邀请关系、设备共享、IP共享、WiFi共享、支付账号共享，设备型号

### 算法步骤

1. 计算图节点\(用户\)连通分量，找出所有相互连通的群体
2. Louvain社区发现，细分团伙边界
3. 计算团伙特征，规模、设备密度、IP集中度 ，邀请闭环系数（三角形计数），注册时间集中度
4. 计算团伙风险评分，输出高风险团伙

### 输出字段

- 团伙ID
- 成员数
- 风险分
- 头目账号
- 作弊手法标签

# 算法实现

在实际工业界风控中，很少有单一模型能解决所有问题，通常建议分层融合：

1. 第一层（过滤层）：使用JS散度, DTW时序模式匹配，无监督模型 \(iForest\) 和 频繁项集 \(FP\-Growth\) 快速筛选出明显聚集的异常流量。
2. 第二层（识别层）：利用 XGBoost 对通过第一层的流量进行精确打分。
3. 第三层（深挖层）：针对图建模挖掘出的团伙子图，进行人工审核或自动拉黑，同时将其作为标签反哺第二层的监督模型。

根据我们的算法落地经验，注意如下要点:

- 如果资源有限，可以从JS散度和 XGBoost \+ 基础频繁项集入手；
- 如果面临明确的团伙攻击（营销费用损失大），图神经网络是打击团伙欺诈的首选方案。
- 如果业务冷启动，可以参考业界的风控物料库，比如针对手机号的虚拟号段，解码平台号段检测；针对ip的机房/住宅类型检测；可以引入设备环境检测辅助判断等

# ==================== 第一部分：数据生成 ====================

def generate_normal_user_invites(user_id, base_time, invite_count):
    """
    生成正常用户的邀请时间序列
    特征：时间间隔呈指数分布（随机、稀疏）
    
    参数:
        user_id: 用户ID
        base_time: 起始时间
        invite_count: 邀请次数
    
    返回:
        邀请时间列表
    """
    # 正常间隔：均值15分钟，指数分布（有长尾）
    intervals = np.random.exponential(scale=900, size=invite_count - 1)  # 900秒 = 15分钟
    intervals = np.clip(intervals, 60, 86400)  # 限制在1分钟到24小时之间
    
    invite_times = [base_time]
    for interval in intervals:
        invite_times.append(invite_times[-1] + timedelta(seconds=interval))
    
    return invite_times[1:]  # 返回邀请时间列表（不含首次）


def generate_cheat_user_invites(user_id, base_time, invite_count, interval_seconds=30):
    """
    生成作弊用户的邀请时间序列
    特征：时间间隔高度均匀（脚本批量邀请）
    
    参数:
        user_id: 用户ID
        base_time: 起始时间
        invite_count: 邀请次数
        interval_seconds: 固定间隔（秒）
    
    返回:
        邀请时间列表
    """
    # 作弊间隔：固定间隔 ± 微小抖动
    intervals = np.random.normal(loc=interval_seconds, scale=interval_seconds * 0.05, size=invite_count - 1)
    intervals = np.clip(intervals, interval_seconds * 0.9, interval_seconds * 1.1)
    
    invite_times = [base_time]
    for interval in intervals:
        invite_times.append(invite_times[-1] + timedelta(seconds=interval))
    
    return invite_times[1:]


def generate_mixed_user_invites(user_id, base_time, invite_count):
    """
    生成混合行为用户（先正常后作弊，或反之）
    
    参数:
        user_id: 用户ID
        base_time: 起始时间
        invite_count: 邀请次数
    
    返回:
        邀请时间列表
    """
    split_point = invite_count // 2
    normal_intervals = np.random.exponential(scale=900, size=split_point - 1)
    cheat_intervals = np.random.normal(loc=30, scale=2, size=invite_count - split_point)
    
    intervals = np.concatenate([normal_intervals, cheat_intervals])
    np.random.shuffle(intervals)
    
    invite_times = [base_time]
    for interval in intervals:
        invite_times.append(invite_times[-1] + timedelta(seconds=interval))
    
    return invite_times[1:]


def create_dataset(sample_count=2000):
    """
    生成包含正常、作弊、混合用户的完整数据集
    
    参数:
        sample_count: 总样本数量
    
    返回:
        data_df: 包含用户数据的DataFrame
        labels: 标签数组 (0: 正常, 1: 作弊/异常)
    """
    data = []
    labels = []
    
    # 正常用户 (40%)
    for i in range(int(sample_count * 0.4)):
        user_id = f"normal_{i}"
        invite_count = np.random.randint(3, 20)
        base_time = datetime(2025, 1, 1, 10, 0, 0) + timedelta(days=np.random.randint(0, 30))
        invite_times = generate_normal_user_invites(user_id, base_time, invite_count)
        
        data.append({
            'user_id': user_id,
            'invite_count': len(invite_times),
            'invite_times': invite_times,
            'interval_seconds': [(invite_times[i] - invite_times[i-1]).total_seconds() 
                                 for i in range(1, len(invite_times))] if len(invite_times) > 1 else []
        })
        labels.append(0)  # 0: 正常
    
    # 作弊用户 (40%)
    for i in range(int(sample_count * 0.4)):
        user_id = f"cheat_{i}"
        invite_count = np.random.randint(10, 50)
        base_time = datetime(2025, 1, 1, 10, 0, 0) + timedelta(days=np.random.randint(0, 30))
        interval_seconds = np.random.choice([10, 20, 30, 60])  # 不同作弊速度
        invite_times = generate_cheat_user_invites(user_id, base_time, invite_count, interval_seconds)
        
        data.append({
            'user_id': user_id,
            'invite_count': len(invite_times),
            'invite_times': invite_times,
            'interval_seconds': [(invite_times[i] - invite_times[i-1]).total_seconds() 
                                 for i in range(1, len(invite_times))] if len(invite_times) > 1 else []
        })
        labels.append(1)  # 1: 作弊
    
    # 混合用户 (20%)
    for i in range(int(sample_count * 0.2)):
        user_id = f"mixed_{i}"
        invite_count = np.random.randint(15, 40)
        base_time = datetime(2025, 1, 1, 10, 0, 0) + timedelta(days=np.random.randint(0, 30))
        invite_times = generate_mixed_user_invites(user_id, base_time, invite_count)
        
        data.append({
            'user_id': user_id,
            'invite_count': len(invite_times),
            'invite_times': invite_times,
            'interval_seconds': [(invite_times[i] - invite_times[i-1]).total_seconds() 
                                 for i in range(1, len(invite_times))] if len(invite_times) > 1 else []
        })
        labels.append(1)  # 混合行为也标记为异常
    
    return pd.DataFrame(data), np.array(labels)

def build_reference_templates():
    """
    构建不同作弊模式的参考模板序列
    用于DTW距离计算
    
    返回:
        templates: 模板字典
    """
    templates = {}
    
    # 模板1: 极速批量邀请（每10秒一次）
    templates['fast_batch'] = [10] * 20
    
    # 模板2: 中等速度批量邀请（每30秒一次）
    templates['medium_batch'] = [30] * 20
    
    # 模板3: 慢速批量邀请（每60秒一次）
    templates['slow_batch'] = [60] * 20
    
    # 模板4: 均匀邀请（固定间隔，带微小抖动）
    templates['uniform_with_jitter'] = [30 + np.random.normal(0, 2) for _ in range(20)]
    
    # 模板5: 随机邀请（正常行为模板，用于对比）
    templates['random_normal'] = np.random.exponential(scale=900, size=20).tolist()
    
    return templates

                'interval_iqr': 0,
                'interval_autocorr_lag1': 0,
                'uniformity_score': 0,
                'very_short_ratio': 0,
                'very_long_ratio': 0,
                'fft_peak_freq': 0
            })
            continue
        
        intervals = np.array(intervals)
        
        # 基础统计
        mean_val = np.mean(intervals)
        std_val = np.std(intervals)
        cv_val = std_val / mean_val if mean_val > 0 else 0
        
        # 偏度和峰度
        skew_val = stats.skew(intervals) if len(intervals) >= 3 else 0
        kurt_val = stats.kurtosis(intervals) if len(intervals) >= 4 else 0
        
        # 分位数
        q25 = np.percentile(intervals, 25)
        q75 = np.percentile(intervals, 75)
        iqr = q75 - q25
        
        # 自相关（lag=1）
        autocorr = np.corrcoef(intervals[:-1], intervals[1:])[0, 1] if len(intervals) > 1 else 0
        if np.isnan(autocorr):
            autocorr = 0
        
        # 均匀性得分：间隔标准差与均值的比值越小越均匀
        uniformity = 1 - (cv_val / (1 + cv_val))  # 越接近1越均匀
        
        # 异常间隔占比（极短或极长）
        very_short_ratio = np.sum(intervals < 60) / len(intervals)  # <1分钟
        very_long_ratio = np.sum(intervals > 3600) / len(intervals)  # >1小时
        
        # FFT峰值频率（周期性检测）
        if len(intervals) > 3:
            fft_vals = np.abs(np.fft.fft(intervals))
            if len(fft_vals) > 2:
                fft_peak_freq = np.argmax(fft_vals[1:len(fft_vals)//2]) / len(intervals)
            else:
                fft_peak_freq = 0
        else:
            fft_peak_freq = 0
        
        features_list.append({
            'invite_count': len(intervals),
            'interval_mean': mean_val,
            'interval_std': std_val,
            'interval_cv': cv_val,
            'interval_skew': skew_val,
            'interval_kurtosis': kurt_val,
            'interval_min': intervals.min(),
            'interval_max': intervals.max(),
            'interval_median': np.median(intervals),
            'interval_q25': q25,
            'interval_q75': q75,
            'interval_iqr': iqr,
            'interval_autocorr_lag1': autocorr,
            'uniformity_score': uniformity,
            'very_short_ratio': very_short_ratio,
            'very_long_ratio': very_long_ratio,
            'fft_peak_freq': fft_peak_freq
        })
    
    return pd.DataFrame(features_list)


def extract_dtw_features(interval_sequences, templates, max_seq_length=50):
    """
    为每个用户提取DTW相关特征
    
    参数:
        interval_sequences: 每个用户的邀请间隔序列列表
        templates: 参考模板字典
        max_seq_length: 序列最大长度（用于填充或截断）
    
    返回:
        features_df: 包含DTW特征的DataFrame
    """
    dtw_features = []
    
    for idx, intervals in enumerate(interval_sequences):
        if len(intervals) == 0:
            # 无邀请行为
            row = {f'dtw_dist_to_{k}': 999 for k in templates.keys()}
            row['dtw_min_distance'] = 999
            row['dtw_best_match'] = 'unknown'
            dtw_features.append(row)
            continue
        
        # 序列标准化：转换为累积比例（关注节奏而非绝对值）
        cumsum = np.cumsum(intervals)
        seq = cumsum / cumsum[-1] if cumsum[-1] > 0 else cumsum
        
        # 如果序列过长，截断；过短，填充
        if len(seq) > max_seq_length:
            seq = seq[:max_seq_length]
        elif len(seq) < max_seq_length:
            # 用最后一个值填充
            seq = np.append(seq, [seq[-1]] * (max_seq_length - len(seq)))
        
        row = {}
        distances = []
        
        # 计算与每个模板的DTW距离
        for template_name, template_seq in templates.items():
            try:
                # 确保模板长度匹配
                template = template_seq[:max_seq_length] if len(template_seq) > max_seq_length else template_seq
                if len(template) < max_seq_length:
                    template = template + [template[-1]] * (max_seq_length - len(template))
                
                # 将模板也转换为累积比例
                template_cumsum = np.cumsum(template)
                template_normalized = template_cumsum / template_cumsum[-1] if template_cumsum[-1] > 0 else template_cumsum
                
                # 计算DTW距离并归一化
                distance = dtw.distance(seq, template_normalized)
                normalized_distance = distance / max(len(seq), len(template_normalized))
                row[f'dtw_dist_to_{template_name}'] = normalized_distance
                distances.append(normalized_distance)
                
            except Exception as e:
                row[f'dtw_dist_to_{template_name}'] = 999
                distances.append(999)
        
        # 添加与模板的最小距离
        row['dtw_min_distance'] = min(distances) if distances else 999
        if distances:
            best_idx = np.argmin(distances)
            row['dtw_best_match'] = list(templates.keys())[best_idx]
        else:
            row['dtw_best_match'] = 'unknown'
        
        dtw_features.append(row)
    
    return pd.DataFrame(dtw_features)


def cap_outliers(df, cols, lower_percentile=1, upper_percentile=99):
    """
    对异常值进行截断处理
    
    参数:
        df: 输入DataFrame
        cols: 需要处理的列名列表
        lower_percentile: 下界百分位数
        upper_percentile: 上界百分位数
    
    返回:
        df_capped: 处理后的DataFrame
    """
    df_capped = df.copy()
    for col in cols:
        if col in df_capped.columns:
            lower = df_capped[col].quantile(lower_percentile / 100)
            upper = df_capped[col].quantile(upper_percentile / 100)
            df_capped[col] = df_capped[col].clip(lower, upper)
    return df_capped


# ==================== 第四部分：DTW + XGBoost 检测器类 ====================

class DTWXGBoostDetector:
    """
    DTW + XGBoost 异常邀请检测器
    
    使用流程:
        1. 初始化检测器
        2. 调用fit方法训练模型
        3. 调用predict方法进行预测
    
    示例:
        detector = DTWXGBoostDetector()
        detector.fit(interval_sequences, labels)
        predictions, probabilities = detector.predict(new_sequences)
    """
    
    def __init__(self, reference_templates=None):
        """
        初始化检测器
        
        参数:
            reference_templates: 参考模板字典，默认使用内置模板
        """
        self.reference_templates = reference_templates or build_reference_templates()
        self.model = None
        self.feature_columns = None
        
    def prepare_features(self, interval_sequences):
        """
        准备完整特征集（统计特征 + DTW特征）
        
        参数:
            interval_sequences: 每个用户的邀请间隔序列列表
        
        返回:
            feature_df: 完整的特征DataFrame
        """
        # 提取统计特征
        stat_df = extract_statistical_features(interval_sequences)
        
        # 提取DTW特征
        dtw_df = extract_dtw_features(interval_sequences, self.reference_templates)
        
        # 合并特征
        feature_df = pd.concat([stat_df, dtw_df], axis=1)
        
        # 编码最佳匹配
        if 'dtw_best_match' in feature_df.columns:
            match_mapping = {name: idx for idx, name in enumerate(self.reference_templates.keys())}
            feature_df['dtw_best_match_encoded'] = feature_df['dtw_best_match'].map(match_mapping).fillna(-1)
            feature_df = feature_df.drop(['dtw_best_match'], axis=1)
        
        return feature_df
    
    def fit(self, interval_sequences, labels, eval_ratio=0.2, verbose=True):
        """
        训练XGBoost模型
        
        参数:
            interval_sequences: 每个用户的邀请间隔序列列表
            labels: 标签数组 (0: 正常, 1: 作弊)
            eval_ratio: 验证集比例
            verbose: 是否打印训练信息
        
        返回:
            self: 训练好的检测器
        """
        # 准备特征
        X = self.prepare_features(interval_sequences)
        self.feature_columns = X.columns.tolist()
        
        # 划分训练集和验证集
        X_train, X_val, y_train, y_val = train_test_split(
            X, labels, test_size=eval_ratio, random_state=42, stratify=labels
        )
        
        # 处理异常值
        numeric_cols = [col for col in X_train.columns if col not in ['dtw_best_match_encoded']]
        X_train = cap_outliers(X_train, numeric_cols)
        X_val = cap_outliers(X_val, numeric_cols)
        
        # 计算样本权重（处理类别不平衡）
        scale_pos_weight = (y_train == 0).sum() / (y_train == 1).sum()
        
        if verbose:
            print(f"训练集大小: {len(X_train)}, 验证集大小: {len(X_val)}")
            print(f"正负样本比例: {(y_train==1).sum()}/{(y_train==0).sum()}")
            print(f"scale_pos_weight: {scale_pos_weight:.4f}")
        
        # 模型参数
        params = {
            'n_estimators': 200,
            'max_depth': 6,
            'learning_rate': 0.1,
            'subsample': 0.8,
            'colsample_bytree': 0.8,
            'min_child_weight': 3,
            'scale_pos_weight': scale_pos_weight,
            'random_state': 42,
            'eval_metric': 'auc',
            'verbosity': 0 if not verbose else 1
        }
        
        # 创建并训练模型
        self.model = xgb.XGBClassifier(**params)
        
        if verbose:
            print("\n开始训练XGBoost模型...")
        
        self.model.fit(
            X_train, y_train,
            eval_set=[(X_train, y_train), (X_val, y_val)],
            verbose=False
        )
        
        if verbose:
            print("训练完成!")
        
        return self
    
    def predict(self, interval_sequences, threshold=0.5):
        """
        预测新用户的邀请行为是否异常
        
        参数:
            interval_sequences: 每个用户的邀请间隔序列列表
            threshold: 判断为作弊的概率阈值
        
        返回:
            predictions: 预测标签数组
            probabilities: 预测概率数组
        """
        if self.model is None:
            raise ValueError("模型尚未训练，请先调用fit方法")
        
        # 准备特征
        X = self.prepare_features(interval_sequences)
        X = X[self.feature_columns]
        
        # 处理异常值
        numeric_cols = [col for col inX.columns if col not in ['dtw_best_match_encoded']]
        X = cap_outliers(X, numeric_cols)
        
        # 预测
        probabilities = self.model.predict_proba(X)[:, 1]
        predictions = (probabilities >= threshold).astype(int)
        
        return predictions, probabilities
    
    def predict_single(self, interval_sequence, threshold=0.5):
        """
        预测单个用户的邀请行为是否异常
        
        参数:
            interval_sequence: 单个用户的邀请间隔序列
            threshold: 判断为作弊的概率阈值
        
        返回:
            result: 包含预测结果的字典
        """
        predictions, probabilities = self.predict([interval_sequence], threshold)
        
        return {
            'is_cheat': bool(predictions[0]),
            'probability': float(probabilities[0])
        }
    
    def get_feature_importance(self, top_k=20):
        """
        获取特征重要性排序
        
        参数:
            top_k: 返回前k个重要特征
        
        返回:
            importance_df: 特征重要性DataFrame
        """
        if self.model is None:
            raise ValueError("模型尚未训练，请先调用fit方法")
        
        importance_df = pd.DataFrame({
            'feature': self.feature_columns,
            'importance': self.model.feature_importances_
        }).sort_values('importance', ascending=False)
        
        return importance_df.head(top_k)
    
    def evaluate(self, interval_sequences, labels):
        """
        评估模型性能
        
        参数:
            interval_sequences: 测试集的间隔序列
            labels: 测试集的真实标签
        
        返回:
            report: 分类报告
            auc: AUC分数
        """
        predictions, probabilities = self.predict(interval_sequences)
        
        auc = roc_auc_score(labels, probabilities)
        report = classification_report(labels, predictions, target_names=['正常', '作弊'])
        
        return report, auc
    
    def save(self, filepath='dtw_xgb_model.pkl'):
        """
        保存模型到文件
        
        参数:
            filepath: 保存路径
        """
        with open(filepath, 'wb') as f:
            pickle.dump(self, f)
        print(f"模型已保存至: {filepath}")
    
    @classmethod
    def load(cls, filepath='dtw_xgb_model.pkl'):
        """
        从文件加载模型
        
        参数:
            filepath: 模型文件路径
        
        返回:
            detector: 加载的检测器实例
        """
        with open(filepath, 'rb') as f:
            detector = pickle.load(f)
        print(f"模型已加载: {filepath}")
        return detector

def detect_new_user_from_timestamps(invite_timestamps, detector, threshold=0.5):
    """
    从时间戳列表检测新用户的邀请行为是否异常
    
    参数:
        invite_timestamps: 邀请时间戳列表（datetime对象）
        detector: 训练好的检测器
        threshold: 判断为作弊的概率阈值
    
    返回:
        result: 包含检测结果的字典
    """
    if len(invite_timestamps) < 2:
        return {
            'is_cheat': False,
            'probability': 0,
            'message': '邀请数量不足（至少需要2次邀请才能判断）',
            'invite_count': len(invite_timestamps)
        }
    
    # 计算时间间隔
    intervals = []
    for i in range(1, len(invite_timestamps)):
        delta = (invite_timestamps[i] - invite_timestamps[i-1]).total_seconds()
        intervals.append(delta)
    
    # 预测
    result = detector.predict_single(intervals, threshold)
    
    # 添加额外信息
    result['invite_count'] = len(invite_timestamps)
    result['avg_interval'] = np.mean(intervals)
    result['std_interval'] = np.std(intervals)
    result['cv_interval'] = np.std(intervals) / np.mean(intervals) if np.mean(intervals) > 0 else 0
    
    return result
