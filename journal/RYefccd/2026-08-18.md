### 1ms.run 镜像源

1ms.run 付费后支持

**方式一：registry-mirrors（推荐）**

修改 `daemon.json`，拉取时仍用原名：

```json
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.m.daocloud.io"
  ]
}
```

```bash
# 拉取命令不变
docker pull nginx
docker pull redis:7
```

**方式二：镜像前缀（直接替换域名）**

无需改 `daemon.json`，拉取时替换 registry 域名：

```bash
# Docker Hub
docker pull docker.1ms.run/library/nginx
docker pull docker.1ms.run/library/redis:7

# GHCR
docker pull ghcr.1ms.run/linuxserver/webtop:latest

# GCR（付费）
docker pull gcr.1ms.run/google-containers/pause

# K8s（付费）
docker pull k8s.1ms.run/pause
```
